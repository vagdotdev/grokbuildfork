# Why contexts and not counts: the previous baseline (`auth.x.ai 11 / accounts.x.ai 6 /
# api.mixpanel.com 1`) counted raw `strings` lines of the CI debug build. Those numbers are an
# artefact of the build profile — a literal is emitted once per codegen unit that inlines it, and
# adjacent Rust literals (not NUL-terminated) fuse into one `strings` line with whatever
# neighbour the linker placed next to them — so the identical source failed the ratchet as a
# `release-dist` build (16 codegen units) although every hit was one of the strings below.
# Contexts are substrings of the reviewed literals; they match the same way in any profile.
